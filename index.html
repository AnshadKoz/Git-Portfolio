01 / The basics

What is Git?

Git is a distributed version control system that tracks changes in source code.

01 — TRACK

Track every change

See what changed in your project, when it changed, and which commit introduced it.

02 — COLLABORATE

Work as a team

Developers can work on separate branches and combine their work safely.

03 — RECOVER

Keep project history

Review previous versions and investigate problems without losing the project history.

02 / Command reference

Git commands to know

Use the copy buttons to copy a command while practising in your terminal.

git initStart a repository
git statusCheck file changes
git add .Stage all changes
git commit -m "message"Save a snapshot
git log --onelineView commit history
git branchList branches
git switch -c featureCreate and switch branch
git pushSend commits to remote
git pullFetch and integrate changes
git clone URLCopy a remote repository
03 / DevOps workflow

From code to deployment

Git is one part of the delivery process. A CI/CD pipeline can automate the steps that follow.

Developer code→ Git commit→ GitHub→ CI/CD pipeline→ EC2 deployment
04 / Hands-on lab

Your first Git practice

Run these commands inside a test folder on your EC2 instance or local machine.

$ Create your first repository

mkdir my-first-git-project
cd my-first-git-project

git init

echo "Hello DevOps! Learning Git." > index.html

git status
git add .
git commit -m "Add first HTML page"

git log --oneline

After the commit, run git status again. You should see a clean working tree if all changes were committed.
